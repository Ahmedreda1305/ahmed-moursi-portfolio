├── index.html

## Publish on GitHub Pages

1. Log in to GitHub as **ahmedreda1305** and open or create the repository `ahmed-moursi-portfolio` (public).
2. Upload `index.html` and `README.md` to the root of the repository. Commit the files.
3. Open the repository's `assets` folder, or create it using **Add file → Upload files**. Upload `ahmed-moursi-portrait.png` and the `photo-01.jpg`–`photo-15.jpg` files there. Commit the upload.
4. Under **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
5. Open https://ahmedreda1305.github.io/ahmed-moursi-portfolio/ after deployment.

If an image is missing, open its `src` URL from `index.html` and check the exact path and capitalization against the repository file list. The `EN` and `DE` buttons switch language and remember the selection in the browser.
