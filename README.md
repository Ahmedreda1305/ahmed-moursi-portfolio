# Ahmed Moursi — bilingual portfolio

The website is entirely contained in **index.html**. It includes the portrait, project photos, styling, English/German language switch, and contact email. No image folder, CSS, or JavaScript files need to be uploaded.

## Publish or repair GitHub Pages

1. In the `ahmedreda1305/ahmed-moursi-portfolio` repository, upload this **index.html** to the root of the `main` branch. It must be named exactly `index.html`. If GitHub already has an `index.html`, replace its contents with this file. Do not use a timestamped filename.
2. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`, and Save.
3. When deployment finishes, open https://ahmedreda1305.github.io/ahmed-moursi-portfolio/ and force refresh with Ctrl+F5.

You may leave previously uploaded photos in the repository, but this version of the page does not use them. Verify photo-to-project assignment with Ahmed before sharing publicly.
