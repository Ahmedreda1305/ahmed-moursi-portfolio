# Ahmed Moursi — Civil Engineering Portfolio

A responsive static portfolio for GitHub Pages. Open `index.html` locally to preview.

## Before publishing

1. Replace both occurrences of `YOUR_EMAIL@example.com` in `index.html` with Ahmed's preferred contact email, and remove the placeholder note in the contact section.
2. Review project facts, image placement, and Ahmed's precise involvement. The supplied images did not include a verified project-by-project image map; match each photograph to its project before publishing. The site uses descriptive alt text without claiming an exact photo location.
3. Review permission to publish the supplied photographs.

## Publish to GitHub Pages

Create a new public repository in Ahmed's GitHub account, such as `ahmed-moursi-portfolio`. Upload the **contents** of this folder to the repository root. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The site will be available at `https://USERNAME.github.io/ahmed-moursi-portfolio/` after deployment. Replace `USERNAME` with the actual GitHub username.

No build tools or external dependencies are needed.
