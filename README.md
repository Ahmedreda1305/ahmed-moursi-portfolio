# Ahmed Moursi — English / German portfolio

This GitHub Pages portfolio includes the new portrait, five infrastructure projects, and a section showing six supporting documents. All photos and documents are embedded directly in `index.html`, so **you only need to upload `index.html`**. It is normal for this file to be relatively large.

## Upload and publish

1. Open the GitHub repository `ahmedreda1305/ahmed-moursi-portfolio` and select the `main` branch.
2. Remove the old timestamped HTML file (for example `index(20260923-224341).html`) if it is still there. GitHub Pages needs the exact filename `index.html` at the repository root.
3. Select **Add file → Upload files** and upload this `index.html` and, optionally, `README.md`. If an old `index.html` exists, replace its contents using GitHub's file editor instead.
4. Commit to `main`. In **Settings → Pages**, set **Deploy from a branch**, **main**, **/(root)**, then Save.
5. After Pages reports deployment, open https://ahmedreda1305.github.io/ahmed-moursi-portfolio/ and hard refresh (Ctrl+F5). Use **EN / DE** to change language and open a credential to see it full size.

If the repository has a different name, substitute that name in the URL after `github.io/`. A username repository named `ahmedreda1305.github.io` is available directly at `https://ahmedreda1305.github.io/`.
